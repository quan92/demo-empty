# 架构基线：烟花动画 HTML 页面

## 需求来源

本设计依据已批准的需求基线 `docs/wi-t1000374/requirements.md`（sha256:0b1ff9b6e1d07775e7a951b3b603bcb7d88b507df1df0b0b46ba164b6ddcfa4b）。产品语义以该文件为唯一来源，本基线不复制验收场景或业务规则，只给出实现这些语义的最小技术承载方式。

## 应用类型与路线

- 分类结论：`simple-frontend`（精简路线）。
- 判定依据：需求仅要求单个可直接在浏览器打开的 HTML 页面，自动持续播放烟花动画；无服务端权威数据、认证/权限、后台任务、外部集成或跨用户/设备共享数据要求。

## 交付形态

- 交付物为**单个 HTML 文件**（建议命名为工作区根目录下的 `index.html`），CSS 与 JavaScript 全部内联，零外部依赖（无框架、无 CDN 资源、无构建步骤）。
- 选择单文件而非 SPA 工程：需求基线明确"单个 HTML 交付物"，且打开方式为本地文件直接打开或静态服务器访问任一即可；引入 React/Vite 等构建链会增加交付复杂度而无法带来任何被要求的能力。
- 动画渲染使用浏览器原生 `<canvas>` 2D 上下文，配合 `requestAnimationFrame` 驱动动画循环，满足"持续播放、自动呈现"的可观察语义。

## 页面与交互范围

- 页面打开后即自动启动动画主循环，无需任何用户操作。
- 动画内容：烟花弹升空 → 到达高点后绽放为大量彩色粒子向外扩散 → 粒子在重力与衰减作用下消散；旧的烟花消散的同时按固定或随机节奏持续发射新的烟花，保证画面在观察期间始终有动画进行。
- 画布尺寸跟随浏览器视口（监听 `resize` 重设画布），任何窗口大小下动画全屏可见。
- 无路由、无表单、无用户输入、无交互控件（需求未规定交互，保持"无需操作即可观看"的最小范围）。

## 状态与数据归属

- 页面不产生需要持久化的业务数据。运行期内存中维护烟花/粒子对象列表，仅存在于当前页面生命周期；刷新或关闭后不保留，也无需保留。
- 不使用 `localStorage`、Cookie、IndexedDB 或任何网络请求；不存在跨浏览器、跨设备、跨用户的数据归属问题。

## 实现入口与运行方式

- 实现入口：工作区根目录 `index.html`（单文件，代码内联）。
- 运行方式（任一即可，与需求基线一致）：
  1. 在浏览器中直接打开该 HTML 文件（`file://` 方式）；
  2. 或在工作区根目录以任意静态服务器托管后访问（例如 `npx serve .` 或等效静态托管）。
- 无后端服务、无构建产物、无部署环境依赖。

## 边界声明

- 不设计也不虚构：服务/API、数据库、认证、后台任务、外部集成、同步层、多页面结构。
- 不生成技术契约、workspace-bootstrap、ADR 或实现计划文档；本路线仅此一份基线文档。
- 声音效果、交互控制（暂停/点击发射等）、性能参数细节在需求中未规定，实现时保持在"自动持续播放的纯观看动画"范围内，不扩展产品语义。
