# 需求：烟花动画 HTML 页面

## 目标

用户明确提出：画一个 HTML 页面，显示烟花的动画。即交付一个可直接在浏览器中打开的 HTML 页面，页面呈现烟花绽放的动画效果。

## 核心行为与规则

- 页面为单个 HTML 交付物，用户打开页面后无需任何操作即可看到烟花动画（用户明确提出"显示烟花的动画"）。
- 动画应呈现烟花的典型视觉效果：升空后绽放扩散、随后消散（推荐基线：用户明确了"烟花动画"这一对象，此为其核心可观察含义；具体视觉细节如颜色、数量、频率未规定）。
- 动画持续播放，不是仅出现一次后静止（推荐基线：与"动画"的可观察含义一致）。
- 打开方式（本地文件直接打开或静态服务器访问）未规定，任一方式可用即可。

## 验收场景

### AC-01：打开页面可看到烟花动画
- 验收条件：用户在浏览器中打开该 HTML 页面后，页面上出现烟花绽放的动画，且动画持续进行。
- 入口类型：用户界面
- 验证动作：在浏览器中打开该页面并观察画面。
- 预期结果：页面无需用户点击或输入即自动呈现烟花动画；可见烟花升空、绽放扩散及消散的动态过程，动画在观察期间持续播放。
- 证据类型：runtime-render

## 范围外

- 无用户或已确认基线明确排除的事项。（用户未提及声音、交互控制、多页面、部署平台等，均保持未规定，不做推断。）
