# 需求：HTML 鹈鹕骑车

## 目标

用户明确提出：创建一个 HTML 页面，画面呈现一只鹈鹕骑在自行车上的场景。

## 核心行为/规则

- 交付物为一个 HTML 文件，用浏览器直接打开即可显示，无需安装、构建或启动服务（用户明确提出载体为 HTML）。
- 页面视觉主体为"鹈鹕骑自行车"：画面中可辨认出一只鹈鹕（喙、身形等主要特征可辨），且鹈鹕处于骑在自行车上的姿态（坐于车上，与车把/踏板的位置关系可辨）。
- 画面风格、配色、画面尺寸未规定；以简洁、形象可辨的视觉呈现闭合核心目标即可（推荐基线，可按用户后续反馈调整）。
- 是否加入动画（如车轮转动、背景移动）未规定；静态画面即满足核心目标，动画属于后续可选增强，不纳入本次验收。
- 未规定多设备适配、交互操作、数据持久化等要求；本次不包含这些内容。

## 验收场景

### AC-01：浏览器打开页面呈现鹈鹕骑自行车的画面
- 验收条件：在浏览器中直接打开交付的 HTML 文件后，页面正常显示，画面呈现一只鹈鹕骑在自行车上的可辨认场景。
- 入口类型：用户界面
- 验证动作：用浏览器打开交付的 HTML 文件，观察页面渲染结果。
- 预期结果：页面正常渲染，无空白页、无报错；画面中鹈鹕与自行车的形象均可辨认，鹈鹕呈现骑在自行车上的姿态。
- 证据类型：runtime-render,visual-style
