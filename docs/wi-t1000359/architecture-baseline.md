# 架构基线：HTML 鹈鹕骑车

## 需求基线引用

本设计基于已批准的需求快照 `docs/wi-t1000359/requirements.md`（sha256:b9c0cec2597b33a85c86f4e3d75488185ff21bbb8c95cb622fb112edfc61f27d）。产品语义以该快照为唯一来源，本文档只给出实现所需的最小技术承载方式，不扩展或重裁产品语义。

## 应用形态与路线

- 路线：simple-frontend（compact）。需求明确交付物为一个 HTML 文件，浏览器直接打开即可显示，无需安装、构建或启动服务，因此不引入 React/Vite 构建链，采用单文件静态 HTML 承载。
- 应用形态：单文件静态页面，无多页面路由、无组件框架、无包管理与构建步骤。

## 页面与交互范围

- 单页面、纯视觉呈现：画面主体为"鹈鹕骑自行车"场景，鹈鹕特征（喙、身形）与自行车形象可辨认，且鹈鹕呈现骑坐姿态（与车把、踏板的位置关系可辨）。
- 无交互操作、无表单、无状态切换；画面风格、配色、尺寸以简洁、形象可辨为基线，具体视觉细节留待实现阶段确定，可按用户后续反馈调整。
- 动画（如车轮转动、背景移动）为后续可选增强，不纳入本基线的实现范围。

## 浏览器状态与数据归属

- 无用户数据、无持久化需求：不使用 localStorage、Cookie 或任何存储；不涉及跨页面、跨设备、跨用户的数据共享。
- 无服务端权威数据、无认证/权限、无后台任务、无外部服务集成、无同步层。

## 实现入口与运行方式

- 实现入口：单个 HTML 文件（工作区根目录下交付，文件名由实现阶段确定，如 `index.html`），CSS 与图形（SVG）全部内联于该文件，无外部资源依赖（字体、图片、脚本均内联或使用系统默认），确保 `file://` 直接打开即可完整渲染。
- 图形承载：以内联 SVG 绘制鹈鹕与自行车主体，保证喙、身形、骑姿等关键特征可辨；内联 CSS 负责页面布局、尺寸与配色。
- 运行方式：浏览器直接打开该 HTML 文件（双击或 `file://` 路径）即可显示；无需开发服务器、无需构建命令。如后续需要，任何静态文件服务器均可托管，但非必需。

## 技术约束与边界

- 不虚构服务/API、数据库、认证、后台任务、外部集成或同步层；不生成技术契约、ADR 或实现计划文档。
- 兼容边界：面向现代桌面浏览器（Chromium/Firefox/WebKit 最新稳定版）的静态渲染即可，不做多设备适配承诺。

## 验收覆盖（内部清单）

- AC-01：由单文件页面在浏览器中的实际渲染结果覆盖，关注点——页面正常渲染无报错、鹈鹕与自行车形象可辨认、骑坐姿态可辨；证据类型为 runtime-render 与 visual-style。
